# Worldbuilding Vault

An Obsidian vault and worldbuilding framework for a tabletop RPG setting (system: Daggerheart).

This repo is currently an **empty framework**: folder structure, conventions, and templates are in place, ready for a new setting to be built into it. See `CLAUDE.md` for how the vault is organized and `00 - Core/Meta/Conventions.md` for the front-matter schema and folder tree.
