# Reveal Index

> **Machine-and-GM index.** Each `reveal_tag` → the secret note → player notes that list it in `reveals:` → notes whose GM walls expose it but front-matter is missing. Procedure: [[Revelation Architecture]]. Strip rule: [[Conventions#Player-safe export]].

`leaf-mother-is-real` is confirmation (or the keystone's own tag). `keystone-adjacent` is clue without confirmation. Household / Unspent / fire tags mark notes that expose those secrets, usually behind `## GM Notes`. A tag on a mixed note does **not** mean the remaining player body spoils after the wall is stripped — campaign filter step 5 still requires that the leftover body would spoil.

Condition hubs/cards stay `reveals: []` unless the *player body* confirms a secret, or a GM wall names a Hand (`the-other-hands` on Bound and Returned). Phoenix and the hub stay empty on purpose.

## How to use this in export

1. Omit `visibility: gm` notes.
2. Strip `## GM Notes` (and `GM —` blockquotes, HTML comments) per [[Conventions#Player-safe export]].
3. Optional: drop notes whose `reveals` still contain an unrevealed tag **and** whose remaining body would spoil that tag. Do not hide [[Conditions]] or [[Kind Heritage]] this way.
